# Defensive Windows CMD Reference

<Callout type="warning" title="Auditing Privilege Scope">
Several diagnostics (scheduled tasks, full service lists) require an **Elevated Command Prompt (Administrator)** to return complete results.
</Callout>

This reference covers auditing Windows systems using the built-in CMD shell — verifying system properties, accounts, active processes, and network ports without third-party binaries.

## Cheat sheet checklist

| Defensive audit target | Command | Goal |
| --- | --- | --- |
| Active sockets | `netstat -ano` | Map ports to PIDs |
| System profile | `systeminfo` | OS build, patches, uptime |
| Active users | `net user` | Local account inventory |
| Administrators | `net localgroup administrators` | Privileged group membership |
| Process inspection | `tasklist /v` | Running processes with window titles |
| Active shares | `net share` | Network-exposed folders |
| Running services | `sc query state= all` | Background service state |

## 1. Network sockets and PID auditing

Monitoring open ports and linking them to parent processes is a core endpoint verification step.

### Listing mapped sockets

<TerminalCommand cmd="netstat -ano" />

* `-a` — all connections and listening ports
* `-n` — numeric addresses (skip DNS resolution)
* `-o` — append owning Process ID (PID)

### Link PID to executable

<TerminalCommand cmd='tasklist /fi "PID eq 4012"' />

## 2. User accounts and group membership

Unauthorized accounts or group changes are common persistence indicators.

<TerminalCommand cmd="net localgroup administrators" />

> **Defensive checklist:** Compare administrators group output against your corporate baseline. Investigate unexpected accounts immediately.

## 3. Services and scheduled tasks

<TerminalCommand cmd="sc query state= all" />
