# Defensive Windows CMD Reference
This reference covers auditing Windows systems using the built-in CMD command shell. These commands allow you to verify system properties, accounts, active processes, and network ports without installing external binaries.
&lt;Callout type="warning" title="Auditing Privilege Scope"&gt;
Several diagnostics command strings (such as querying scheduled tasks or active services) must be executed within an **Elevated Command Prompt (Administrator Mode)** to display complete logs.
&lt;/Callout&gt;
## Cheat Sheet Checklist
| Defensive Audit Target | Command Syntax | Functional Goal |
| **Active Sockets** | `netstat -ano` | List all active ports mapped to PID numbers. |
| **System Profile** | `systeminfo` | View OS build, installation date, and hotfixes. |
| **Active Users** | `net user` | Audit all configured local user accounts. |
| **Local Administrators** | `net localgroup administrators` | Inspect accounts assigned to the local Administrator group. |
| **Process Inspection** | `tasklist /v` | List active processes with detailed window titles. |
| **Active Shares** | `net share` | Identify folder structures shared on the network. |
## 1. Network Sockets & PID Auditing
Monitoring open network ports and identifying their parent processes is a critical step in verifying endpoint security.
### Listing Mapped Sockets
Use `netstat` to view listening and established TCP/UDP connections:
&lt;TerminalCommand cmd="netstat -ano" /&gt;
*   `-a`: Show all active connections and listening ports.
*   `-n`: Output numbers for addresses and ports instead of resolving names.
*   `-o`: Append the parent Process ID (PID) associated with each connection.
### Linking PID to Executable
Once you identify a suspicious PID in the `netstat` output (e.g., `4012`), verify the executable name using `tasklist`:
&lt;TerminalCommand cmd='tasklist /fi "PID eq 4012"' /&gt;
## 2. User Accounts & Group Membership Audits
Unauthorized accounts or group modifications are primary indicators of persistence.
### Auditing Group Membership
Verify who has administrative control over the machine:
&lt;TerminalCommand cmd="net localgroup administrators" /&gt;
> **Defensive Checklist:** Regularly compare administrators group outputs against the corporate baseline. Investigate any unexpected accounts.
## 3. Auditing Running Services & Tasks
Auditing services helps identify running background processes and check for persistence vectors.
### Listing Active Windows Services
Query the Service Control Manager to list currently running background services:
&lt;TerminalCommand cmd="sc query state= all" /&gt;
