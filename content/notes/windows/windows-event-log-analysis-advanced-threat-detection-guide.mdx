## Log sources overview

| Log | Path (default) | Primary use |
| --- | --- | --- |
| Security | `%SystemRoot%\System32\Winevt\Logs\Security.evtx` | Auth, object access, policy changes |
| System | `...\System.evtx` | Services, drivers, shutdown events |
| PowerShell Operational | `Microsoft-Windows-PowerShell%4Operational.evtx` | Script block logging (4103–4104) |
| Sysmon Operational | `Microsoft-Windows-Sysmon%4Operational.evtx` | Process, network, file telemetry |
| Windows Defender | `Microsoft-Windows-Windows Defender%4Operational.evtx` | Detection and remediation events |

Enable **Advanced Audit Policy** and **PowerShell Script Block Logging** before relying on these sources in production.

## Critical Security Event IDs

### Authentication and logon

| Event ID | Meaning | Hunt priority |
| --- | --- | --- |
| 4624 | Successful logon | Baseline + anomaly detection |
| 4625 | Failed logon | Brute force, password spray |
| 4648 | Explicit credential logon | Lateral movement (RunAs / net use) |
| 4672 | Special privileges assigned | Admin/sensitive logon |
| 4768 / 4769 | Kerberos TGT / service ticket | Golden ticket, unusual SPN requests |
| 4776 | NTLM authentication | Legacy auth abuse |

**Logon types to filter:** Type 3 (network), Type 10 (RDP), Type 2 (interactive).

### Privilege and group changes

| Event ID | Meaning | Hunt priority |
| --- | --- | --- |
| 4673 / 4674 | Privileged service / object operation | High |
| 4728 / 4732 / 4756 | Member added to domain/local/universal group | Critical |
| 4698–4702 | Scheduled task created/modified/deleted | Persistence |

### Lateral movement indicators

| Pattern | Event IDs | Notes |
| --- | --- | --- |
| Network logon from new source IP | 4624 (Type 3) | Correlate with 4648 on destination |
| RDP session | 4624 (Type 10), 4778, 4779 | Unusual off-hours access |
| New service install | 7045 (System) | PsExec-style remote services |
| WMI activity | 5857+ (WMI-Activity) | Remote execution |
| PS Remoting | 4103, 4104 (PowerShell) | Script content in 4104 |

### Persistence

| Technique | Event IDs | Log |
| --- | --- | --- |
| Registry Run keys | 4657, 4663 | Security |
| Scheduled tasks | 4698–4702 | Security |
| Service creation | 4697, 7045 | Security / System |
| WMI subscriptions | 5857–5861 | WMI-Activity |

## Investigation workflow

```text
Alert or hypothesis → Scope hosts/time → Pull Security + Sysmon + PowerShell → Build timeline → Correlate IPs/accounts → Validate on endpoint → Document IOCs
```

### Quick PowerShell queries

Failed logons (last 24 hours):

```powershell
$start = (Get-Date).AddHours(-24)
Get-WinEvent -FilterHashtable @{
  LogName = 'Security'
  Id = 4625
  StartTime = $start
} -MaxEvents 100 |
  Select-Object TimeCreated,
    @{N='Account';E={$_.Properties[5].Value}},
    @{N='SourceIP';E={$_.Properties[19].Value}}
```

Network logons with source IP:

```powershell
Get-WinEvent -FilterHashtable @{
  LogName = 'Security'
  Id = 4624
  StartTime = (Get-Date).AddHours(-24)
} |
  Where-Object { $_.Properties[8].Value -eq 3 } |
  Select-Object TimeCreated,
    @{N='Account';E={$_.Properties[5].Value}},
    @{N='SourceIP';E={$_.Properties[18].Value}}
```

For more cmdlet patterns see [PowerShell Auditing](/notes/windows/powershell-auditing).

## Timeline and correlation

1. **Anchor event** — first 4625 burst, 7045 service install, or Defender alert.
2. **Expand window** — ±2 hours on affected hosts.
3. **Join sources** — Security logon + Sysmon process create (Event 1) + PowerShell 4104.
4. **Cross-system** — same account or source IP across multiple endpoints.
5. **Validate** — live process list, service config, scheduled tasks on suspect host.

Pair host evidence with [Wireshark](/notes/networking/wireshark) PCAP when network confirmation is needed.
