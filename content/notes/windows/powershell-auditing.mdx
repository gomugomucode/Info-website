# PowerShell Auditing & Threat Detection

PowerShell is the primary shell for Windows threat hunting and host auditing. This guide covers event log queries, service misconfiguration checks, and process/network baselines.

<Callout type="tip" title="Execution scope">
Run `Set-ExecutionPolicy RemoteSigned -Scope Process` to allow local scripts in the current session without changing system-wide policy.
</Callout>

## Threat hunting command reference

| Target | Cmdlet | Goal |
| --- | --- | --- |
| Failed logins | `Get-WinEvent` (Security 4625) | Brute force / spray detection |
| Process inventory | `Get-Process` + path | Unsigned or unusual binaries |
| Service paths | `Get-CimInstance Win32_Service` | Unquoted path vectors |
| Listening ports | `Get-NetTCPConnection -State Listen` | Unexpected listeners |

## 1. Querying Security event logs

Failed logon events (Event ID 4625):

```powershell
Get-WinEvent -FilterHashtable @{
  LogName = 'Security'
  Id = 4625
} -MaxEvents 50 |
  Select-Object TimeCreated, Message |
  Format-Table -Wrap
```

Successful logons from network (Type 3) — useful for lateral movement review:

```powershell
Get-WinEvent -FilterHashtable @{
  LogName = 'Security'
  Id = 4624
  StartTime = (Get-Date).AddHours(-24)
} |
  Where-Object { $_.Properties[8].Value -eq 3 } |
  Select-Object TimeCreated,
    @{N='Account';E={$_.Properties[5].Value}},
    @{N='SourceIP';E={$_.Properties[18].Value}}
```

See [Windows Event Log Analysis](/notes/windows/windows-event-log-analysis-advanced-threat-detection-guide) for full Event ID tables.

## 2. Auditing service configurations

Unquoted service paths with spaces can enable privilege escalation when parent directories are writable:

```powershell
Get-CimInstance -ClassName Win32_Service |
  Where-Object { $_.PathName -notlike '"*' -and $_.PathName -like '* *' } |
  Select-Object Name, DisplayName, PathName
```

## 3. Auditing running processes

```powershell
Get-Process |
  Where-Object { $_.Path -ne $null } |
  Select-Object Name, Id, Path |
  Sort-Object Name
```

## 4. Network listeners

```powershell
Get-NetTCPConnection -State Listen |
  Select-Object LocalAddress, LocalPort, OwningProcess,
    @{N='Process';E={(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).Name}} |
  Sort-Object LocalPort
```
