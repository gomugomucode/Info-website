# Windows CLI 100 Commands Every security analyst Should Know compressed
> [!IMPORTANT]
> **Defensive & Authorized Auditing Purposes Only**
> This note is prepared for educational and authorized defensive diagnostics, infrastructure auditing, and host hardening purposes only. Unauthorised access, penetration tests without written consent, or execution of security commands on external networks is illegal.
🖥  SYSTEM INFO & ENUMERATION (1–15)
1. whoami → Show current logged-in user
2. hostname → Show computer name
3. systeminfo → Full OS + patch + hardware info
4. ver → Windows version
5. set → Show environment variables
6. echo %username% → Show username
7. date /t → Show date
8. time /t → Show time
9. driverquery → List installed drivers
10. tasklist → Running processes
11. tasklist /svc → Processes with services
12. wmic os get caption → OS name
13. wmic cpu get name → CPU info
14. wmic bios get serialnumber → BIOS serial
15. wmic qfe → Installed patches (important for vuln
checks)
👤  USER & ACCOUNT ENUMERATION (16–25)
16. net user → List all users
17. net user &lt;user&gt; → User details
18. net localgroup → List groups
19. net localgroup administrators → Admin users
20. whoami /groups → User group membership
21. whoami /priv → User privileges
22. query user → Logged-in users
23. net accounts → Password policy
24. net user &lt;user&gt; /active:no → Disable user
25. net user &lt;user&gt; * → Change password
🌐  NETWORK ENUMERATION (26–45)
26. ipconfig → IP info
27. ipconfig /all → Full network config
28. ipconfig /displaydns → DNS cache
29. ipconfig /flushdns → Clear DNS cache
30. getmac → MAC address
31. arp -a → ARP table
32. route print → Routing table
33. netstat -an → Open ports
34. netstat -ano → Ports + PID
35. netstat -b → Process using port (admin)
36. ping &lt;host&gt; → Test connectivity
37. tracert &lt;host&gt; → Trace route
38. pathping &lt;host&gt; → Ping + route loss
39. nslookup &lt;domain&gt; → DNS lookup
40. net view → Network shares
41. net view \\target → Shares of target
42. nbtstat -n → NetBIOS names
43. nbtstat -A &lt;ip&gt; → NetBIOS info remote
44. net use → Show mapped drives
45. net use \\ip\share → Connect share
📁  FILE & DIRECTORY OPERATIONS (46–60)
46. dir → List files
47. dir /a → Show hidden files
48. tree → Directory tree
49. cd → Change directory
50. mkdir → Create folder
51. rmdir → Remove folder
52. del → Delete file
53. copy → Copy file
54. move → Move file
55. rename → Rename file
56. type file.txt → Read file
57. more file.txt → Read page by page
58. attrib → File attributes
59. attrib +h file → Hide file
60. where file.exe → Find file path
🔎  SEARCH & FORENSICS (61–70)
61. find "text" file.txt → Search string
62. findstr "text" file.txt → Advanced search
63. findstr /s /i password *.* → Search recursively
64. fc file1 file2 → Compare files
65. certutil -hashfile file sha256 → File hash (VERY
important)
66. cipher /c file → Check encryption
67. cipher /w:c → Wipe deleted space
68. compact → Check compression
69. forfiles → Find files by date
70. dir /s filename → Search file

🔐  SECURITY & PERMISSIONS (81–90)
81. icacls file → Show permissions
82. icacls file /grant user:F → Grant access
83. takeown /f file → Take ownership
84. auditpol /get /category:* → Audit policy
85. secedit /export → Security policy
86. gpresult /r → Group policy result
87. gpupdate /force → Update GPO
88. logoff → Log off user
89. shutdown /s /t 0 → Shutdown
90. shutdown /r /t 0 → Restart
🧰  DISK & SYSTEM UTILITIES (91–100)
91. chkdsk → Disk check
92. diskpart → Disk manager
93. sfc /scannow → System file check
94. dism /online /cleanup-image /restorehealth →
Repair Windows
95. mountvol → Volume mount points
96. fsutil fsinfo drives → List drives
97. fsutil file createnew file 1000 → Create file
98. powercfg /a → Power modes
99. wevtutil qe System → Read event logs
100. eventvwr → Open event viewer
