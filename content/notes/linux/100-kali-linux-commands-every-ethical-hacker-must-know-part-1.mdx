Nuclei 
(Template-Based Vulnerability Scanner)
Nuclei is a modern, template-driven vulnerability scanner designed for fast and
scalable detection of security issues across web applications, APIs, cloud
infrastructure, and networks. It uses community-maintained templates to
identify CVEs, misconfigurations, exposures, and security flaws. It is widely used
in bug bounty hunting, red team operations, and automated diagnostic run surface
monitoring.

Amass 
(diagnostic run Surface Discovery and Asset Enumeration)
Amass is an advanced reconnaissance tool used to discover domains,
subdomains, IP addresses, and external assets belonging to a target
organization. It integrates OSINT, DNS enumeration, brute forcing, and
infrastructure mapping techniques. It is essential for diagnostic run surface mapping
and external perimeter analysis.

httpx
(High-Speed HTTP Probing Tool)
httpx is a fast and reliable tool for probing web servers and identifying live hosts,
technologies, HTTP status codes, and exposed services. It is commonly used in
reconnaissance pipelines to validate targets and identify accessible web
infrastructure.

subfinder
(Fast Passive Subdomain Enumeration)
subfinder is a passive reconnaissance tool designed to discover subdomains
using multiple OSINT sources such as search engines, certificate logs, and public
databases. It is extremely fast and widely used in modern bug bounty and red
team workflows.

naabu
(Fast Port Scanner for Modern Recon)
naabu is a high-performance port scanner designed for speed and automation.
It is optimized for scanning large diagnostic run surfaces and integrates seamlessly with
modern reconnaissance tools like nuclei and httpx.

ffuf
(Fast Web Fuzzer for Directory and Parameter Discovery)
ffuf is a fast and flexible web fuzzing tool used for discovering hidden directories,
files, virtual hosts, and parameters. It is commonly used in web application
security testing and content discovery.

Katana
(Modern Web Crawler and diagnostic run Surface Discovery)
Katana is a fast and modern web crawler designed for deep discovery of
endpoints, parameters, and hidden diagnostic run surfaces. It supports JavaScript
parsing, automatic form extraction, and integration with other tools like nuclei. It
is widely used in bug bounty hunting and red team reconnaissance workflows.

Evilginx2
(Advanced Phishing Framework for Credential Capture)
Evilginx2 is an advanced man-in-the-middle framework used for capturing
authentication credentials and session tokens during authorized security
assessments. It uses reverse proxy techniques to intercept login traffic and
analyze authentication flows. It is commonly used in red team engagements to
evaluate identity security and phishing resilience.

enum4linux-ng
(Advanced Windows and SMB Enumeration Tool)
enum4linux-ng is a modern enumeration tool used to extract detailed
information from Windows and SMB services. It can identify users, shares,
policies, domain information, and system configuration. It is essential for internal
network assessments and Active Directory reconnaissance.

mitmproxy
(Interactive Traffic Interception and Analysis Tool)
mitmproxy is an advanced interception proxy used to analyze, inspect, and
modify HTTP and HTTPS traffic in real time. It is widely used for testing web
applications, APIs, and mobile applications. It allows security professionals to
monitor traffic flows and identify vulnerabilities or insecure data handling.
