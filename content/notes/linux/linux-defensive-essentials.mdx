# Linux Defensive CLI Essentials
This guide covers essential command-line tools for inspecting system states, active sessions, SUID permissions, and network sockets. Performing regular audits using these built-in utilities is critical for maintaining robust Linux endpoint security.
&lt;Callout type="warning" title="Educational Purpose Notice"&gt;
All command strings and diagnostic workflows detailed in this document must be executed exclusively on local containers, testing sandboxes, or systems under authorized configuration control.
&lt;/Callout&gt;
## Quick Reference Checklist
Use these commands for rapid diagnostic checks on newly deployed or suspicious Linux hosts:
| Defensive Audit Target | Command Syntax | Functional Goal |
| **Active Sockets** | `ss -tlnp` | List listening TCP ports with associated PIDs. |
| **All Connections** | `ss -tuanpe` | View all TCP/UDP connections with user ownership. |
| **Logged Users** | `who` / `w` | Identify active logged-in users and current tasks. |
| **SUID Binaries** | `find / -perm -4000 -type f 2>/dev/null` | Find files executing with owner root privileges. |
| **System Integrity** | `journalctl -p 3 -xb` | View error logs since the current system boot. |
## 1. Network Connection Auditing
Investigating network sockets using `ss` (Socket Statistics) is faster and more precise than legacy `netstat` commands.
### Listing Listening Services
To identify what services are listening for incoming connections:
&lt;TerminalCommand cmd="ss -tlnp" /&gt;
*   `-t`: Display TCP sockets.
*   `-l`: Show listening sockets only.
*   `-n`: Avoid DNS resolving to improve speed.
*   `-p`: Output the process ID and program name.
### Full Socket Diagnostics
To display all active TCP and UDP connections with extended socket details and process owners:
&lt;TerminalCommand cmd="ss -tuanpe" /&gt;
*   `-u`: Include UDP sockets.
*   `-a`: Show both listening and established states.
*   `-e`: Append user ID and socket statistics.
## 2. Auditing SUID and SGID Permissions
Misconfigured Set-User-ID (SUID) binaries allow general users to run applications with root-level privileges. Malicious actors often target these binaries to escalate privilege bounds.
### Searching for SUID Binaries
Search for executable files that have the SUID bit set:
&lt;TerminalCommand cmd="find / -perm -4000 -type f 2&gt;/dev/null" /&gt;
> **Defensive Tip:** Compare search output against a baseline list of expected SUID binaries (like `/usr/bin/passwd` or `/usr/bin/sudo`). Investigate any newly added binary immediately.
## 3. Investigating User Activity and Logins
Checking who is currently authenticated is the first step in auditing suspected active sessions.
### Active User Overview
Display active terminal users and their current processes:
&lt;TerminalCommand cmd="w" /&gt;
### Reviewing Authentication Logs
On Debian/Ubuntu hosts, authentication events write to `/var/log/auth.log` (or `journalctl` on modern systemd distros):
&lt;TerminalCommand cmd="journalctl -u ssh.service --since '24 hours ago'" /&gt;
