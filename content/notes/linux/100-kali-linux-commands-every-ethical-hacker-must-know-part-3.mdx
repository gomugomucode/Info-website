SQLmap
(Advanced SQL Injection Testing Tool)
SQLmap is an automated tool used to detect and test SQL injection
vulnerabilities in web applications. It can enumerate databases,
extract data, and analyze backend database structures during
authorized security assessments.

Nikto
(Web Server Vulnerability Scanner)
Nikto is a web server scanner that detects outdated software,
misconfigurations, exposed files, and common vulnerabilities. It is
widely used for quick security assessments of web infrastructure.

WPScan
(WordPress Security Scanner)
WPScan is a security scanner designed to identify vulnerabilities in
WordPress installations. It detects outdated plugins, themes,
exposed users, and misconfigurations.

Hydra
(Network Login Testing Tool)
Hydra is a fast network login testing tool that supports multiple
protocols such as SSH, FTP, HTTP, and RDP. It is used to test
authentication security in controlled environments.

John the Ripper
(Password Cracking Tool)
John the Ripper is a password analysis tool used to test password
strength by performing hash cracking in authorized security
assessments. It supports multiple hash formats and diagnostic run modes.

TheHarvester
(WordPress Security Scanner)
theHarvester is an OSINT reconnaissance tool used to collect emails,
subdomains, IPs, and public data from search engines and public
sources. It is commonly used during the early reconnaissance phase
of security assessments.

DNSRecon
(DNS Enumeration Tool)
DNSRecon is used to perform DNS enumeration, zone transfers, and
subdomain discovery. It helps analyze DNS configurations and
identify exposed records.

Autorecon
(Automated Reconnaissance Tool)
Autorecon automates network reconnaissance by combining
multiple scanning tools into a structured workflow. It is useful for
quickly identifying services and gathering actionable information.

pspy
(Linux Process Monitoring Tool)
pspy is a lightweight Linux tool used to monitor running processes
without root privileges. It helps identify scheduled tasks, cron jobs,
and automated processes during security assessments.

Searchsploit
(security diagnostic test Database Search Tool)
Searchsploit is a command-line interface for searching the security diagnostic test
Database. It allows security professionals to quickly find publicly
available security diagnostic test references related to specific services or
vulnerabilities.
