# Master Termux Handbook

<Callout type="warning" title="Authorized Use Only">
Use Termux tools only on networks and systems you own or have explicit written permission to test.
</Callout>

Termux provides a sandboxed Linux environment on Android. Install packages, run Python/Node scripts, use SSH, and perform authorized security learning from a mobile lab — after completing [Linux CLI Essentials](/notes/linux/essential-linux-commands-for-cybersecurity-specialists).

## Installation

Install from [F-Droid](https://f-droid.org) (recommended). The Play Store version is outdated and no longer maintained.

<Callout type="info" title="Sandbox Scope">
Termux operates within the Android application sandbox. It does not have root access to the Android host unless you explicitly configure root on the device.
</Callout>

## Quick Setup

<TerminalCommand cmd="pkg update && pkg install openssh nmap dnsutils tracepath tsu -y" />

## Storage & Sandboxing

By default, Termux cannot access shared Android storage. Grant access with:

<TerminalCommand cmd="termux-setup-storage" />

This creates a `$HOME/storage` link to standard Android paths like `/sdcard/`.

## Network Auditing from Mobile

### Local IP and routing

<TerminalCommand cmd="ip route show" />

### Port scan (authorized targets only)

<TerminalCommand cmd="nmap -sT -F 192.168.1.1" />

## SSH Server on Termux

Run an SSH daemon to manage your phone from a desktop (default port `8022`):

<TerminalCommand cmd="sshd" />

Check your Termux username (e.g., `u0_a123`):

<TerminalCommand cmd="whoami" />

## Top Termux Tools for Security Labs

| Tool | Purpose |
| --- | --- |
| **Nmap** | Network scanning and service fingerprinting |
| **Hydra** | Password auditing on authorized systems |
| **Nikto** | Web server misconfiguration checks |
| **SQLMap** | SQL injection validation in controlled labs |
| **RustScan** | Fast port discovery (pair with Nmap) |
| **Git** | Pull tools, modules, and scripts |
| **Python + pip** | Automation, OSINT, and scripting |
| **Sherlock** | Username OSINT across platforms |
| **Netcat** | Socket testing and connectivity checks |
| **Termux-API** | Android hardware access via scripts |
| **Htop** | Process and resource monitoring |

## What Termux Can Do

- Run Linux commands and package-managed tools
- Support Python, Node.js, Git, and SSH workflows
- Enable automation and legal cybersecurity learning on mobile
- Perform authorized reconnaissance on lab networks
