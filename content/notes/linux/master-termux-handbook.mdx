Termux is a powerful Android app that gives you a full Linux
terminal on your phone. You can install packages, run
scripts, use Python, Git, SSH, and perform many tasks just
like on a real Linux system.
What it does:
Runs Linux commands and packages
Supports Python, Node, Git, etc.
Allows SSH connections
Perfect for automation, development, and legal
cybersecurity learning
How to download it (recommended way):
Install F-Droid from f-droid.org.
Search for Termux.
Download it from there — this is the official updated
version.
(The Play Store version is outdated and no longer
maintained.)

Network scanning, fingerprinting, full recon.
 GitHub: https://github.com/nmap/nmap

Industry-standard exploitation framework for labs & training.

Password-audit tool for your own authorized systems.

4. Nikto
Web server scanner for misconfigurations & outdated
components.
 GitHub: https://github.com/sullo/nikto
5. SQLmap
Automation engine for SQL injection testing in controlled labs.
 GitHub: https://github.com/sqlmapproject/sqlmap
6. RustScan
Ultra-fast port scanner — perfect combo with Nmap.
 GitHub: https://github.com/RustScan/RustScan
7. Wget / cURL
Core tools for fetching data, automation & scripting.
