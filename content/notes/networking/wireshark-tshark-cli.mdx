# TShark & Wireshark Packet Analysis

Wireshark is the standard tool for packet capture and network troubleshooting. TShark is its command-line counterpart, perfect for headless servers, scripts, and parsing large PCAP files. This guide details using the TShark CLI to capture, filter, and inspect traffic.

<Callout type="info" title="Capture Privileges">
Capturing live packets requires raw socket access. Run commands as root (`sudo`) or configure your local system user group to allow capture actions.
</Callout>

## Common Command Operations

| Defensive Task | TShark CLI Syntax |
| :--- | :--- |
| **List Interfaces** | `tshark -D` |
| **Capture Live Sockets** | `tshark -i eth0 -c 100 -w capture.pcap` |
| **Read PCAP File** | `tshark -r capture.pcap -c 20` |
| **Filter HTTP Traffic** | `tshark -r capture.pcap -Y "http.request"` |
| **DNS Request Audit** | `tshark -r capture.pcap -Y "dns.flags.response == 0" -T fields -e dns.qry.name` |

---

## 1. Capturing Live Network Traffic

Identify your active network interfaces before starting a capture.

### Listing Available Adapters
Print all network interfaces to identify target interface names:

<TerminalCommand cmd="tshark -D" />

### Initiating a Live Capture
To capture 500 packets on `eth0` and write them directly to a PCAP file:

<TerminalCommand cmd="tshark -i eth0 -c 500 -w network_log.pcap" />

*   `-i eth0`: Select the interface to capture on.
*   `-c 500`: Stop the capture automatically after 500 packets.
*   `-w network_log.pcap`: Save the raw capture data instead of printing it to the terminal.

---

## 2. Reading and Filtering PCAP Files

Filtering is key to finding specific traffic patterns in large capture files.

### Inspecting Captured Packets
To read and print packet logs with simplified line details:

<TerminalCommand cmd="tshark -r network_log.pcap -c 10" />

### Applying Display Filters
Use display filters (`-Y`) to isolate specific protocols or connections. For example, to isolate HTTP requests:

<TerminalCommand cmd="tshark -r network_log.pcap -Y \"http.request\"" />

---

## 3. Advanced DNS Extraction

DNS queries can reveal suspicious host lookups or domain generation algorithms (DGAs). Extract the requested domain names from DNS query packets:

```bash
tshark -r network_log.pcap -Y "dns.flags.response == 0" -T fields -e dns.qry.name
```

*   `-T fields`: Output specified fields only.
*   `-e dns.qry.name`: Target and extract the DNS query domain name field.
