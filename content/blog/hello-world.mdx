# Launching the Cybersecurity Learning Hub

This site is a structured reference library — not a portfolio or generic dev blog. It organizes field guides, checklists, and learning paths for defensive and authorized offensive security work.

## What changed

The previous developer-focused layout was replaced with:

1. **Topic hubs** under `/notes` — Linux, networking, security, web, and Windows
2. **Pillar pages** — canonical starting points (Wireshark, Nmap, web security fundamentals, blue team guide)
3. **Learning paths** — curated sequences linking guides across hubs
4. **Consolidated content** — duplicate cheat sheets merged; old slugs redirect to pillars

## How content is built

- **MDX** for notes with frontmatter, callouts, and terminal command components
- **Next.js App Router** for static generation and SEO metadata
- **JSON-LD** for Person, WebSite, Article, and Breadcrumb schemas

## Where to start

- New to the library? → [Reference Library](/notes)
- Prefer a guided track? → [Learning Paths](/notes#learning-paths)
- Network forensics? → [Wireshark Guide](/notes/networking/wireshark)

More articles will cover audit workflows, content updates, and hub expansion as guides are rewritten from legacy PDF sources.

## Educational Use Notice

This content is provided strictly for educational purposes, defensive security awareness, system administration, diagnostics, and ethical learning environments.

Always obtain proper authorization before testing systems or networks.
