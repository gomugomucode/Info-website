# Nmap Scanning & Host Discovery
Nmap is a powerful network discovery tool used to map assets, inspect open ports, and verify firewall rules. This guide outlines standard port scanning modes, safe service enumeration, and how network monitoring tools detect scans.
<Callout type="warning" title="Auditing Permissions Notice">
Port scanning generates active network traffic. Ensure you have explicit authorization before scanning networks outside your local container environments or local development networks.
</Callout>

## Scan Type Reference Table

| Scan Strategy | Command Syntax | Use Case / Security Insight |
| --- | --- | --- |
| **SYN Stealth Scan** | `nmap -s S -p- <target>` | Default scan. Sends SYN packets, analyzes responses. |
| **TCP Connect Scan** | `nmap -s T -p <ports> <target>` | Completes 3-way handshake. Used when raw sockets are restricted. |
| **UDP Scan** | `nmap -s U -p <ports> <target>` | Audits UDP services (DNS, DHCP, NTP). Slow but critical. |
| **Service Enumeration** | `nmap -s V -O <target>` | Queries ports to detect software versions and OS. |
| **Safe Scripting Scan** | `nmap -s C <target>` | Runs safe, default scripts to audit system configurations. |
## 1. Core Scanning Methods
Selecting the correct scan mode is key to performing efficient network audits.
### SYN Stealth Scan
To perform a full TCP port scan using the stealthy half-open connection model:
<Terminal Command cmd="nmap -s S -p- 192.168.1.1" />
*   `-s S`: Execute a TCP SYN scan. Does not complete the 3-way handshake.
*   `-p-`: Scan all 65,535 TCP ports.
### TCP Connect Scan
When running under user privilege levels that restrict opening raw sockets, use a TCP Connect scan:
<Terminal Command cmd="nmap -s T -p 22,80,443 192.168.1.1" />
*   `-s T`: Complete the full TCP handshake. Highly visible in application server logs.
## 2. Service and OS Detection
Verifying what version of software is running helps locate outdated and vulnerable software deployments.
### Enumerating Version Details
To query active ports and gather banner details:
<Terminal Command cmd="nmap -s V -O 192.168.1.1" />
*   `-s V`: Probe open ports to determine service name and version details.
*   `-O`: Analyze TCP response packet parameters to identify the operating system.
## 3. Defensive Insight: Detecting Network Scans
As a system defender, you should understand how security tools detect scans.
*   **Log Footprints**: Firewalls, IDS (Snort/Suricata), and SIEMs monitor for multiple connection attempts from a single IP to different ports within a short time.
*   **Mitigation**: Configure rate-limiting on firewalls and block suspicious IPs that trigger automated scan alerts.
